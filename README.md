# Rabbit Head — Desenvolvimento para a Web


## Requisitos mínimos
- PHP 7.4 ou superior (recomendado PHP 8.x)
- MySQL / MariaDB
- Servidor web local (Laragon, XAMPP, Wamp, ou similar)

## Estrutura principal
- `index.php` — homepage (lista de artigos)
- `artigo.php` — página de visualização de artigo por `slug`
- `search.php` — página pública de pesquisa (filtrar por texto, categoria, autor, ordenar por data)
- `partials/navbar.php`, `partials/footer.php` — partials partilhados
- `admin/` — backoffice (artigos, categorias, comentários, utilizadores)
- `css/`, `js/`, `imgs/` — assets
- `dump_db/` - dump da base de dados do laragon rabbit_head
